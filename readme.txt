A reusable, accessible, and performance-focused Gutenberg block toolkit.

== Description ==

BlockForge is a collection of reusable Gutenberg blocks designed with accessibility, performance, and maintainability in mind.

The project focuses on modern WordPress block development using block.json, React, and WordPress's native block editor APIs.

== Installation ==

1. Upload the BlockForge plugin to the `/wp-content/plugins/` directory.
2. Activate BlockForge through the 'Plugins' screen in WordPress.
3. Open the WordPress block editor.
4. Insert a BlockForge block from the block inserter.

== Frequently Asked Questions ==

= What version of WordPress does BlockForge require? =

BlockForge requires WordPress 6.3 or later.

= What version of PHP does BlockForge require? =

BlockForge requires PHP 7.4 or later.
